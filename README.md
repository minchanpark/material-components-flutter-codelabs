# Material Components for Flutter Codelabs

This repository contains the four Shrine codelabs for Material Components for
Flutter, updated for Flutter 3.47.

## Introduction

Codelabs MDC-101 through MDC-104 will guide you through building and integrating one application with MDC-Flutter.

## Source precedence

The Google Codelabs instructions are the source of truth for behavior and for
the boundary between each learning stage:

- [MDC-101: Material Components Basics](https://codelabs.developers.google.com/codelabs/mdc-101-flutter)
- [MDC-102: Material Structure and Layout](https://codelabs.developers.google.com/codelabs/mdc-102-flutter)
- [MDC-103: Material Theming](https://codelabs.developers.google.com/codelabs/mdc-103-flutter)
- [MDC-104: Material Advanced Components](https://codelabs.developers.google.com/codelabs/mdc-104-flutter)

The following community repositories were reviewed as secondary references for
the newer null-safe project structure. Their outdated dependency constraints,
unfinished TODOs, and changes that conflict with the codelabs are intentionally
not copied:

- [mare536 MDC-102 reference](https://github.com/mare536/material-components-flutter-codelabs-102-starter_and_101-complete)
- [Marco-Bubola MDC-103 reference](https://github.com/Marco-Bubola/material-components-flutter-codelabs-103-starter_and_102-complete)

## Branches

| Branch | Codelab state |
| --- | --- |
| `101-starter` | MDC-101 starter |
| `102-starter_and_101-complete` | MDC-101 complete / MDC-102 starter |
| `103-starter_and_102-complete` | MDC-102 complete / MDC-103 starter |
| `104-starter_and_103-complete` | MDC-103 complete / MDC-104 starter |
| `104-complete` | MDC-104 complete |

Each branch supports Android, iOS, web, Windows, macOS, and Linux using current
Flutter-generated platform projects.

## Getting Started
Visit the Google Codelabs links above and check out the matching branch before
starting each stage.
