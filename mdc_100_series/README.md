# MDC-103 starter / MDC-102 complete

This branch contains the completed product grid from
[MDC-102: Material Structure and Layout](https://codelabs.developers.google.com/codelabs/mdc-102-flutter)
and is the starting point for
[MDC-103: Material Theming](https://codelabs.developers.google.com/codelabs/mdc-103-flutter).
The login flow, app bar, two-column product grid, and product cards are in place;
the Shrine color, typography, shape, and asymmetric layout are added in MDC-103.

The project setup is updated for Flutter 3.47.5 and Dart 3.13.4 while keeping
the codelab stage unchanged.

```sh
flutter pub get
flutter run
```
