# Shrine — MDC-101 to MDC-104

This is the completed Shrine app from Google's MDC-101 through MDC-104 Flutter
codelabs, updated for Flutter 3.47.5 and Dart 3.13.4.

The app keeps the codelabs' login, product catalog, Shrine theme, asymmetric
layout, category menu, and animated backdrop. Its code and platform projects
use null safety, Material 3, and current Flutter APIs.

## Run the app

```sh
flutter pub get
flutter run
```

## Verify the project

```sh
flutter analyze
flutter test
flutter build web
```
