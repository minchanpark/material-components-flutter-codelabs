# MDC-101 starter

This branch is the starting point for
[MDC-101: Material Components Basics](https://codelabs.developers.google.com/codelabs/mdc-101-flutter).
It intentionally contains only the Shrine logo and title on the login page;
the text fields and buttons are added while completing MDC-101.

The project setup is updated for Flutter 3.47.5 and Dart 3.13.4 while keeping
the codelab stage unchanged.

```sh
flutter pub get
flutter run
```
