# MDC-104 starter / MDC-103 complete

This branch contains the completed Shrine theme and asymmetric product layout
from [MDC-103: Material Theming](https://codelabs.developers.google.com/codelabs/mdc-103-flutter)
and is the starting point for
[MDC-104: Material Advanced Components](https://codelabs.developers.google.com/codelabs/mdc-104-flutter).
It intentionally keeps the app bar navigation; the Backdrop and category menu
are added while completing MDC-104.

The project setup is updated for Flutter 3.47.5 and Dart 3.13.4 while keeping
the codelab stage unchanged.

```sh
flutter pub get
flutter run
```
